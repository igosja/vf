# vf — frontend

Next.js 16 (App Router, Cache Components, React Compiler), Tailwind CSS 4, Radix UI.
UI is ported from the Materia template in `../frontend2`; the API lives in `../backend`.

```bash
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Structure and layer rules: [ARCHITECTURE.md](ARCHITECTURE.md).
