Write a SQL query to get the top 5 products by revenue for this quarter.

Here's a query that joins orders with products and ranks them by revenue for the current quarter:

sql 
SELECT
  p.name,
  SUM(oi.quantity * oi.unit_price) AS revenue
FROM order_items oi
JOIN orders o   ON o.id = oi.order_id
JOIN products p ON p.id = oi.product_id
WHERE o.created_at >= DATE_TRUNC('quarter', CURRENT_DATE)
  AND o.status = 'completed'
GROUP BY p.name
ORDER BY revenue DESC
LIMIT 5;

It only counts completed orders, so refunds and pending payments won't inflate the totals. If your database is MySQL, swap DATE_TRUNC for MAKEDATE(YEAR(CURDATE()), 1) plus a quarter offset.
