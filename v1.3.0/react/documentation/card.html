Card

Almost everything in Materia sits on a card: dashboard widgets, forms, lists and tables. Card from src/components/ui/card.tsx is a white box with rounded corners and 24 pixels of padding. It has no border and no shadow, and the page background sets it apart. Its demo page is at /components/card.

The parts

Part What it is
Card The box. A flex column with rounded-2xl bg-card p-6
CardHeader A row for the title and the actions
CardTitle The title, as an <h5> in text-base font-medium and the emphasis color
CardDescription A line of small, muted text under the title
CardAction A row of small buttons on the right of the header
CardContent The body. It adds no styles of its own
CardFooter A row at the bottom, often for buttons

The parts add no spacing between each other. You set the gaps with margin classes, so each card can be as tight or as open as its content needs.

A form card

import { Button } from "@/components/ui/button";
import { Card, CardAction, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/components/ui/card";
import { Field, FieldGroup, FieldLabel } from "@/components/ui/field";
import { Input } from "@/components/ui/input";

export default function CardForm() {
	return (
		<Card className="w-full max-w-sm">
			<CardHeader className="mb-6">
				<div className="flex-1">
					<CardTitle className="mt-0 mb-1">Login to your account</CardTitle>
					<CardDescription>Enter your email below to login to your account</CardDescription>
				</div>
				<CardAction className="mt-0">
					<Button variant="link" size="sm">
						Sign Up
					</Button>
				</CardAction>
			</CardHeader>
			<CardContent>
				<form>
					<FieldGroup>
						<Field>
							<FieldLabel htmlFor="card-email">Email</FieldLabel>
							<Input id="card-email" type="email" placeholder="m@example.com" required />
						</Field>
						<Field>
							<FieldLabel htmlFor="card-password">Password</FieldLabel>
							<Input id="card-password" type="password" required />
						</Field>
					</FieldGroup>
				</form>
			</CardContent>
			<CardFooter className="mt-6 flex-col gap-2">
				<Button type="submit" className="w-full">
					Login
				</Button>
				<Button variant="outline" className="w-full">
					Login with Google
				</Button>
			</CardFooter>
		</Card>
	);
}

Dashboard cards

Dashboard widgets follow two patterns. The stat cards at the top of each dashboard lay out an icon tile, a number and a label in a row. The larger cards have an icon tile and a title on the left, and small icon buttons on the right.

import { CircleArrowUp, CircleDollarSign, Info, Layers } from "lucide-react";

import { IconButton } from "@/components/common/icon-button";
import { Badge } from "@/components/ui/badge";
import { Card, CardAction, CardHeader, CardTitle } from "@/components/ui/card";

export default function DashboardCards() {
	return (
		<div className="grid gap-4">
			<Card className="flex-row gap-4 p-5 leading-none">
				<span className="grid avatar-mask size-10.5 shrink-0 place-items-center bg-cyan-500/15 text-cyan-500">
					<CircleDollarSign className="size-5.5" />
				</span>
				<div className="flex-1 text-emphasis-foreground">
					<div className="mb-1 flex items-center">
						<div className="mr-2 mb-1 text-lg leading-none font-medium text-cyan-500">$84,156</div>
						<Badge variant="positive" className="-mt-1 ml-auto">
							<CircleArrowUp />
							6.4%
						</Badge>
					</div>
					Monthly recurring revenue
				</div>
			</Card>

			<Card>
				<CardHeader className="mb-4">
					<CardTitle className="-mt-0.5 flex items-center gap-3">
						<span className="grid avatar-mask size-8 place-items-center bg-purple-400/15 text-purple-400">
							<Layers />
						</span>
						Plan Mix
					</CardTitle>
					<CardAction>

							<Info />
							<span className="sr-only">Information</span>

			</Card>
		</div>
	);
}

The icon tile only shows from 640px wide in the template, with hidden ... sm:grid in place of grid. On phones the title starts at the left edge and saves the room.

Changing the padding

className overrides the card’s own classes, so set the padding you need:

<Card className="p-0">
	<div className="border-b px-5 py-4">Header with its own padding</div>
	{/* a table that runs to the edges */}
</Card>

The stat cards use p-5, and cards holding a table use p-0 and pad their own rows.

To run one block to the card’s edges while the rest keeps its padding, pull it out with negative margins equal to the padding:

<CardContent className="-mx-6 px-6">...</CardContent>

Hover inside a card

hover:bg-accent shows a lighter fill on a card than on the page background, so list rows inside a card get a hover color that suits the white background. src/styles/themes.css sets this up for every element with bg-card or bg-popover. Theme Tokens explains the rule.

The Navigate menu

Pages with toc on their content header list every CardTitle in a Navigate menu. Each card gets an id from its title, and the menu jumps to it. The card’s scroll-mt-16 leaves room for the sticky header when it scrolls into view.
