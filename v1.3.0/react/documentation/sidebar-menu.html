Sidebar Menu

The sidebar menu comes from one data file, src/data/navigation.ts. To add, rename, move or remove a link, edit that file. The sidebar component reads it and draws the menu, so you do not touch the component itself.

How the menu looks

The menu has five sections: Dashboards, Applications, Pages, Content and Components.

  • On wide screens (1280px and up), a rail down the left edge shows one icon per section. Pointing at an icon, or moving to it with the keyboard, opens that section’s links in a panel that slides out from behind the rail. The section that holds the current page stays highlighted.
  • On smaller screens, the rail is hidden. The menu button in the content header, or in the bottom bar on phones, opens a drawer with every section listed one under the other.

Both read the same data, so a change to navigation.ts shows up in both.

The data

navigation.ts exports NAVIGATION, a list of sections:

export type NavSection = {
	label: string;
	icon: LucideIcon;
	items: NavItem[];
};

Each section holds items. An item is either a link or a group:

export type NavLink = {
	label: string;
	to: string;
	icon: LucideIcon;
};

/** A link with children opens in place instead of navigating. */
export type NavGroup = {
	label: string;
	icon: LucideIcon;
	children: { label: string; to: string }[];
};

A link goes straight to a page. A group has no page of its own: clicking it opens a list of child links underneath it, as the User and UI Elements groups do.

Add a link

  1. Create the page and add its route. Adding a Page covers both.
  2. Import an icon at the top of navigation.ts. Pick one on the Icons page at /content/icons:
import { Receipt } from "lucide-react";
  1. Add the link to a section, in the position you want it to appear:
{ label: "Orders", to: "/orders", icon: Receipt },

The to value must match the path of the route in src/routes.tsx, with a leading slash.

Add a group

Give the item children in place of to:

{
	label: "Reports",
	icon: FileChartColumn,
	children: [
		{ label: "Sales", to: "/reports/sales" },
		{ label: "Customers", to: "/reports/customers" },
	],
},

A group opens on its own when one of its children is the current page.

Add a section

Add an object to NAVIGATION. Each section needs a short label, because the label sits under its icon in the rail:

{
	label: "Reports",
	icon: ChartColumnBig,
	items: [
		{ label: "Sales", to: "/reports/sales", icon: CircleDollarSign },
		{ label: "Customers", to: "/reports/customers", icon: Users },
	],
},

The rail fits about seven sections on a screen of average height. Group related links together before you add an eighth.

Remove or reorder

Delete an item, or move it within the list. The menu follows the order of the array. When you remove a page for good, also delete its route and its folder. Removing Features explains the steps.

How the current page is found

The sidebar highlights the link whose to matches the address. A link also counts as current on the pages under it, so the AI Agent link stays highlighted on /apps/ai-agent/chat. matchesPath in src/components/layout/sidebar/nav-list.tsx handles this:

export const matchesPath = (to: string, pathname: string) => (to === "/" ? pathname === "/" : pathname === to || pathname.startsWith(`${to}/`));

The home page link, /, only matches the home page. Without that exception it would match every address.

Keyboard

The rail works with the keyboard. Tab to a section icon to open its links, use the up and down arrow keys to move between sections, press Enter, Space or the right arrow to move into the links, and press Escape to close the panel.

Files

File What it does
src/data/navigation.ts The sections, links and groups
src/components/layout/sidebar/sidebar.tsx The rail, the flyout panel and the drawer
