Template Components

Besides the shadcn/ui components, the template has its own components for pieces that repeat across pages. They live in src/components/common and src/components/charts.

Component File What it is
IconButton common/icon-button.tsx The small icon button in card and page headers
ActionButton common/action-button.tsx The main button of an app page: Compose, Upload, Create New
Avatar common/avatar.tsx A photo, or an initial on a colored tile
ListRowAvatar common/list-row-avatar.tsx An avatar that turns into a checkbox when you point at its row
SearchField common/search-field.tsx The pill-shaped search field
DateRangePicker common/date-range-picker.tsx The date range button in the dashboard headers
Trend common/trend.tsx A change figure with an up or down arrow
DialogHead, DialogFoot, DismissButton common/dialog-parts.tsx The title row and button row of a dialog
Lightbox common/lightbox.tsx A full-window photo viewer
RichTextEditor common/rich-text-editor.tsx The formatted text editor
Logo common/logo.tsx The template’s logo
ExampleCard, ExampleSection, Preview common/example.tsx The cards on the component and content pages
ChartLegend charts/chart-legend.tsx The dot-and-label key under a chart
VectorMap charts/vector-map.tsx A map

IconButton, SearchField and DateRangePicker

import { Download, Info } from "lucide-react";

import { DateRangePicker } from "@/components/common/date-range-picker";
import { IconButton } from "@/components/common/icon-button";
import { SearchField } from "@/components/common/search-field";

export default function HeaderTools() {
	return (
		<div className="flex flex-wrap items-center gap-3">
			<SearchField className="w-64" placeholder="Search..." aria-label="Search" shortcut />
			<DateRangePicker defaultValue={{ from: new Date(2026, 9, 1), to: new Date(2026, 9, 31) }} />
			<div className="flex gap-1.5">
				<IconButton>
					<Download />
					<span className="sr-only">Download</span>
				</IconButton>
				<IconButton>
					<Info />
					<span className="sr-only">Information</span>
				</IconButton>
			</div>
		</div>
	);
}

IconButton is a 32-pixel button in the avatar shape that fills on hover. Every icon-only button in a card header or a page header uses it. Put the icon and a hidden label inside:

<IconButton>
	<Download />
	<span className="sr-only">Download</span>
</IconButton>

It is a plain <button> with type="button", so it takes onClick and every other button attribute.

SearchField is a text input in a pill with a search icon. It takes every <input> attribute, such as placeholder, value and onChange. With shortcut, it shows a ⌘K hint (Ctrl K on Windows and Linux) and focuses the field when the visitor presses that key. Use shortcut on one search field per page.

DateRangePicker shows a start and an end date and opens a calendar to change them. Pass the starting range as defaultValue. It keeps the chosen range in its own state, so to filter your data by it, add an onChange prop that passes the range up.

Avatar and ListRowAvatar

import { useState } from "react";

import { Avatar } from "@/components/common/avatar";
import { ListRowAvatar } from "@/components/common/list-row-avatar";

export default function Avatars() {
	const [checked, setChecked] = useState(false);

	return (
		<div className="flex flex-col gap-5">
			<div className="flex items-center gap-3">
				<Avatar src="/img/contacts/2.jpg" alt="Harper Collins" />
				<Avatar src="/img/contacts/5.jpg" alt="Liam Turner" className="size-10" />
				<Avatar initial="M" color="bg-emerald-500" />
				<Avatar initial="J" color="bg-purple-400" className="size-10" />
			</div>

			<div className="group/row flex items-center gap-3 rounded-xl bg-card p-3">
				<ListRowAvatar src="/img/contacts/8.jpg" label="Sofia Martinez" checked={checked} onCheckedChange={setChecked} />
				<span className="text-emphasis-foreground">Sofia Martinez</span>
				<span className="ml-auto text-xs text-muted-foreground">Point at the row</span>
			</div>
		</div>
	);
}

Avatar shows a photo when you pass src. Without a photo, it shows initial on a tile colored by color, a background class. It is 32 pixels by default. Pass a size class to change it:

<Avatar src="/img/contacts/2.jpg" alt="Harper Collins" />
<Avatar initial="M" color="bg-emerald-500" className="size-10" />

ListRowAvatar sits at the start of a selectable list row, as in Mail and Contacts. When the pointer is over the row, the avatar turns into a checkbox, and the checkbox stays while the row is selected. The row needs the group/row class:

<div className="group/row flex items-center gap-3">
	<ListRowAvatar src={contact.photo} label={contact.name} checked={selected} onCheckedChange={setSelected} />
	{contact.name}
</div>

label names the checkbox for screen readers: “Select Sofia Martinez”.

Trend

import { Trend } from "@/components/common/trend";

export default function Trends() {
	return (
		<div className="flex flex-wrap items-center gap-6">
			<Trend>24.99%</Trend>
			<Trend up={false}>9.39%</Trend>
			<Trend positive={false}>8.07%</Trend>
			<Trend iconEnd>3.54%</Trend>
		</div>
	);
}
Prop Default What it does
up true The direction of the arrow. Also sets the color: green when up, red when down
positive Same as up Overrides the color, for a figure where a rise is bad news, such as a bounce rate or a cost
iconEnd false Puts a smaller arrow after the figure, as list rows show it 
<Trend>24.99%</Trend>
<Trend up={false}>9.39%</Trend>
<Trend positive={false}>8.07%</Trend>
<Trend up={item.up} iconEnd className="hidden sm:flex">{item.change}%</Trend>

className passes layout classes through, such as spacing or hiding the trend on phones.

Lightbox

Lightbox shows photos one at a time over a dark backdrop, with arrows, the arrow keys and swipe to move between them. The Photos app and the User Photos page use it:

const [viewing, setViewing] = useState({ open: false, index: 0 });

<Lightbox
	photos={ALL_PHOTOS}
	open={viewing.open}
	index={viewing.index}
	onOpenChange={(open) => setViewing((current) => ({ ...current, open }))}
	actions={
		<IconButton className={lightboxAction}>
			<Download />
			<span className="sr-only">Download</span>
		</IconButton>
	}
/>
Prop What it is
photos A list of image addresses
open, onOpenChange Whether the viewer is open, and the function that opens or closes it
index The photo it opens on
actions Buttons for the top bar. Give each one the lightboxAction class, which styles it for the dark backdrop

To open the viewer on a photo, set open to true and index to the photo’s position, for example from the photo’s onClick.
