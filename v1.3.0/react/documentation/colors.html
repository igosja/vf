Colors

Materia colors everything with two kinds of color:

  • Theme colors have a role in their name: background, card, foreground, border, primary. Each one holds a different value in light and dark mode, so a page built from them works in both modes with no extra classes. Use them for surfaces, text, borders and interactive states. Theme Tokens lists all of them.
  • Palette colors come straight from Tailwind’s built-in palette: sky-500, emerald-500, amber-400 and so on. They look the same in light and dark mode. Use them for meaning: status, categories, chart series and icon tiles.

This page covers the palette colors, plus the two theme colors that carry meaning, primary and destructive. Every class name below is the one the template uses. If you stick to these classes, a new widget will match the ones already in the template.

The palette

Color What it means in Materia Background Text Chart color
Sky The template’s blue for display: information, the default badge, progress bars, the first series in a chart bg-sky-500 text-sky-500 CHART_COLORS.sky
Emerald Good news: growth, success, paid, active, completed, values going up bg-emerald-500 text-emerald-500 CHART_COLORS.emerald
Red Bad news: errors, failures, overdue items, values going down, destructive actions bg-red-400 text-red-400 CHART_COLORS.red
Amber Caution: pending, waiting, delayed and warnings. Charts also use it for the comparison series, such as last month next to this month bg-amber-400 text-amber-500 CHART_COLORS.amber
Cyan A category color with no status meaning bg-cyan-500 text-cyan-500 CHART_COLORS.cyan
Purple A category color bg-purple-400 text-purple-400 CHART_COLORS.purple
Teal A category color bg-teal-500 text-teal-500 CHART_COLORS.teal
Pink A category color bg-pink-400 text-pink-400 CHART_COLORS.pink
Lime A category color bg-lime-500 text-lime-500 CHART_COLORS.lime
Indigo A category color bg-indigo-400 text-indigo-500 CHART_COLORS.indigo

Category colors tell series, people, files and plans apart. They say nothing about good or bad, so keep emerald, red and amber for status and pick from the category colors for everything else.

Amber and indigo use a darker shade for text than for backgrounds. Text has to read on a white card, and amber-400 is too pale for that.

Other utilities

Borders, rings, fills and strokes use the background shade:

Color Border Ring Fill and stroke
Sky border-sky-500 ring-sky-500 fill-sky-500, stroke-sky-500
Emerald border-emerald-500 ring-emerald-500 fill-emerald-500, stroke-emerald-500
Red border-red-400 ring-red-400 fill-red-400, stroke-red-400
Amber border-amber-400 ring-amber-400 fill-amber-400, stroke-amber-400

The category colors follow the same rule: border-cyan-500, ring-purple-400, fill-teal-500 and so on.

Opacity steps

Add / and a number to any palette class to make it see-through. The template uses a small set of steps, each for one job:

Step Example Used for
/10 bg-emerald-500/10 Badge and alert backgrounds
/15 bg-teal-500/15 Icon tiles and soft highlights
/25, /30 bg-sky-500/25 Legend chips for the faded series in a chart
/50 border-red-400/50 Soft borders around a tinted box

Primary and destructive

Two theme colors carry meaning, so they belong on this page as well.

primary is the color of actions. The default button, focus outlines, checked checkboxes, radios and switches, the active menu item, the selected tab and the slider track all use it. Its value is #118bff, the same in light and dark mode, and primary-foreground (white) is the text color that sits on top of it.

Use Class
Solid fill bg-primary with text-primary-foreground
Tint bg-primary/10
Text and icons text-primary
Borders, rings and outlines border-primary, ring-primary, outline-primary

primary and sky-500 are close but not equal. Use primary for anything a person can click or select, and sky-500 for display: badges, chart series and progress bars.

destructive is red-400 under another name. The shadcn components use it for invalid fields and for destructive items in a dropdown menu, so a form error and a red badge share one red.

Links use a third theme color, link, through text-link. It is #1e91ff in light mode and #007ef7 in dark mode.

Status

Status comes from components, so you seldom write a status color by hand. The Badge component has a variant for each status, and the Trend component turns green or red on its own.

import { Trend } from "@/components/common/trend";
import { Badge } from "@/components/ui/badge";

export default function StatusColors() {
	return (
		<div className="flex flex-wrap items-center gap-3">
			<Badge variant="positive">Paid</Badge>
			<Badge variant="caution">Pending</Badge>
			<Badge variant="destructive">Failed</Badge>
			<Badge>Trial</Badge>
			<Trend>24.99%</Trend>
			<Trend up={false}>9.39%</Trend>
		</div>
	);
}
Status Badge variant Color
Good: paid, active, completed, on track positive Emerald
Waiting: pending, delayed, past due caution Amber
Bad: failed, canceled, at risk destructive Red
Neutral or informational: trial, planned default Sky

When a table column holds a status, map each value to a variant once, at the top of the file. The Recent Orders card on the E-commerce dashboard does it this way:

type BadgeVariant = ComponentProps<typeof Badge>["variant"];

const STATUS_VARIANT: Record<RecentOrder["status"], BadgeVariant> = {
	Paid: "positive",
	Failed: "destructive",
	Pending: "caution",
};

<Badge variant={STATUS_VARIANT[item.status]}>{item.status}</Badge>

Trend shows a change with an arrow. It is green when up is true, the default, and red when it is false. Pass positive={false} for a metric where a rise is bad news, such as a bounce rate: the arrow points up and the color turns red.

<Trend>24.99%</Trend>
<Trend up={false}>9.39%</Trend>
<Trend positive={false}>8.07%</Trend>

Common patterns

Icon tiles

The icon at the start of a card title sits on a tinted tile: the color at /15 for the tile and the full color for the icon. avatar-mask gives the tile its rounded four-lobed shape.

import { ChartColumn, Handshake, Pointer, ShoppingBag, Users } from "lucide-react";

export default function IconTiles() {
	return (
		<div className="flex flex-wrap gap-3">
			<span className="grid avatar-mask size-8 place-items-center bg-sky-500/15 text-sky-500">
				<ChartColumn />
			</span>
			<span className="grid avatar-mask size-8 place-items-center bg-emerald-500/15 text-emerald-500">
				<Pointer />
			</span>
			<span className="grid avatar-mask size-8 place-items-center bg-amber-400/15 text-amber-500">
				<ShoppingBag />
			</span>
			<span className="grid avatar-mask size-8 place-items-center bg-teal-500/15 text-teal-500">
				<Users />
			</span>
			<span className="grid avatar-mask size-8 place-items-center bg-purple-400/15 text-purple-400">
				<Handshake />
			</span>
		</div>
	);
}

Legend dots and bars that follow the text color

A data file often stores one text class per item, such as color: "text-cyan-500". The dot then takes bg-current, which paints it in the current text color. One class in the data file colors the dot, the label and anything else that uses currentColor.

import { cn } from "@/lib/utils";

const PLANS = [
	{ plan: "Starter", subscribers: 1420, color: "text-cyan-500" },
	{ plan: "Pro", subscribers: 1126, color: "text-sky-500" },
	{ plan: "Business", subscribers: 548, color: "text-purple-400" },
	{ plan: "Enterprise", subscribers: 154, color: "text-amber-500" },
];

export default function LegendDots() {
	return (
		<div className="flex flex-col gap-2">
			{PLANS.map((item) => (
				<div key={item.plan} className="flex items-center gap-3">
					<i className={cn("size-2.5 shrink-0 rounded-full bg-current", item.color)} />
					<span className="flex-1 text-emphasis-foreground">{item.plan}</span>
					<span className="text-muted-foreground">{item.subscribers}</span>
				</div>
			))}
		</div>
	);
}

Progress bars work the same way. The bar takes its color from the text color, so a text-* class on the Progress component colors it. With no class it is sky.

import { Progress } from "@/components/ui/progress";

export default function ProgressColors() {
	return (
		<div className="flex flex-col gap-4">
			<Progress value={72} aria-label="Default" />
			<Progress value={58} aria-label="Completed" className="text-emerald-500" />
			<Progress value={34} aria-label="Overdue" className="text-red-400" />
		</div>
	);
}

Text on a solid color

White text works on a solid palette color in light mode and black text works in dark mode, so these elements carry text-white dark:text-black. The Avatar component does this for its initials, and the badges on the Billing page do it too.

import { Avatar } from "@/components/common/avatar";

export default function SolidColors() {
	return (
		<div className="flex flex-wrap gap-3">
			<Avatar initial="A" color="bg-sky-500" />
			<Avatar initial="M" color="bg-emerald-500" />
			<Avatar initial="J" color="bg-amber-400" />
			<Avatar initial="R" color="bg-red-400" />
			<Avatar initial="K" color="bg-purple-400" />
		</div>
	);
}

Charts and maps

Chart.js draws on a canvas, and a canvas cannot read a Tailwind class. Charts get their colors from CHART_COLORS in src/components/charts/use-chart-theme.ts. Each key takes the name of a palette color and holds the same shade as that color’s background class, so CHART_COLORS.amber matches bg-amber-400.

export const CHART_COLORS = {
	sky: paletteColor("--color-sky-500"),
	indigo: paletteColor("--color-indigo-400"),
	purple: paletteColor("--color-purple-400"),
	pink: paletteColor("--color-pink-400"),
	red: paletteColor("--color-red-400"),
	amber: paletteColor("--color-amber-400"),
	lime: paletteColor("--color-lime-500"),
	emerald: paletteColor("--color-emerald-500"),
	teal: paletteColor("--color-teal-500"),
	cyan: paletteColor("--color-cyan-500"),
};

paletteColor() reads a Tailwind color from the stylesheet and returns it as rgb(r g b), the format Chart.js understands. Use it for a shade that CHART_COLORS does not hold. The map on the Email Marketing dashboard reads a darker amber for its markers this way:

const MARKER = paletteColor("--color-amber-600");

For a see-through version of a chart color, wrap it in alpha(). Area charts use it for the fade under the line:

backgroundColor: (context) => areaGradient(context, 0.75, alpha(CHART_COLORS.emerald, 0.25), alpha(CHART_COLORS.emerald, 0)),
borderColor: CHART_COLORS.emerald,

Do not write a color into a chart as a hex code or an RGB value. Go through CHART_COLORS, paletteColor() and alpha(), so a chart always matches the classes around it. Chart Colors covers the rest of the chart theme.

Light and dark mode

Palette colors keep the same value in both modes. A few components darken their text by one shade in light mode, so the text reads on a pale tint, and switch back in dark mode:

positive: "bg-emerald-500/10 text-emerald-600 dark:text-emerald-500",

That line is the positive variant in src/components/ui/badge.tsx. Use dark: the same way wherever an element needs a different shade in dark mode. When a theme color already does the job, such as text-foreground or bg-card, use the theme color instead.

Changing colors

To change the primary color, open src/styles/index.css and edit this line:

--color-primary: #118bff;

Every button, focus outline, checked control and active menu item follows.

To swap a palette color, replace its classes across src/ and update the matching key in CHART_COLORS. Moving amber to orange means:

  1. Replace bg-amber-400 with bg-orange-400 and text-amber-500 with text-orange-500, along with the border-, fill- and stroke- classes.
  2. In use-chart-theme.ts, point the key at the new color: amber: paletteColor("--color-orange-400"). Rename the key to orange if you prefer, and update the places that use it.

To add a chart color, add a key to CHART_COLORS with the shade that matches its background class:

rose: paletteColor("--color-rose-400"),

Every color in Tailwind’s palette is available, because src/styles/index.css imports Tailwind with theme(static). That option keeps the full set of color variables in the stylesheet, including shades no class uses yet, so paletteColor() can always read them.

To change a theme color, such as the page background or the card color, edit src/styles/themes.css. Theme Tokens explains each one.
