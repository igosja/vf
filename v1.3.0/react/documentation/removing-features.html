Removing Features

The template ships with more pages than most apps need. Removing the ones you do not use keeps your project easy to find your way around. The build output gets smaller too, although each page already loads only when someone opens it.

Removing a page

Every page takes the same three steps:

  1. Delete its folder in src/pages/. The Teams page lives in src/pages/pages/teams/.
  2. Delete its route in src/routes.tsx, the entry whose import() points at that folder.
  3. Delete its menu link in src/data/navigation.ts, the item whose to matches the route.

Then run the type check:

npm run typecheck

If anything else imported a file from the deleted folder, TypeScript names the file and the line. Fix or remove those imports and run it again.

Last, delete the page’s data file in src/data/ if no other page uses it. Search src/ for the file’s name to check: @/data/teams.

Removing a whole section

To remove a menu section, such as Content or Components, delete its pages as above, then delete the whole section object from NAVIGATION in src/data/navigation.ts.

The demo sections are the safest to remove from a real app:

Section Folders
UI element pages src/pages/components/ except charts and maps if you keep those
Form pages src/pages/forms/
Content pages src/pages/content/

These pages only show what the components can do. The components themselves stay in src/components/ui for your own pages to use.

ExampleCard, ExampleSection and Preview in src/components/common/example.tsx exist for these demo pages. Once the demo pages are gone, delete example.tsx too.

Removing a feature and its packages

Some features bring their own package. Remove the files first, then uninstall the package, so the type check can point at anything you missed.

Calendar

  1. Delete src/pages/apps/calendar/ and src/data/calendar.ts, the route, and the menu link.
  2. Delete src/styles/fullcalendar.css, and its import line in src/styles/index.css.
  3. Uninstall the packages:
npm uninstall @fullcalendar/core @fullcalendar/react @fullcalendar/daygrid @fullcalendar/timegrid

Maps

The Maps page, and the map cards on the Analytics, CRM and Email Marketing dashboards, use VectorMap.

  1. Delete src/pages/components/maps/, its route and its menu link. Delete the folder src/components/charts/maps/ as well. Only the Maps page imports it.
  2. If you also remove the three dashboard map cards (sessions-by-country.tsx, leads-distribution.tsx and geographical-engagements.tsx, along with their places in each page.tsx), nothing uses maps any more. Delete src/components/charts/vector-map.tsx, src/styles/jsvectormap.css and src/types/jsvectormap.d.ts, then uninstall the package:
npm uninstall jsvectormap

Also remove the --chart-map lines from src/styles/themes.css.

Rich text editor

The Messages app and the Rich Text Editor page use it. After removing both, or replacing the editor in Messages with a Textarea:

  1. Delete src/components/common/rich-text-editor.tsx and src/styles/quill.css.
  2. Uninstall the package:
npm uninstall quill

Form validation

Only the Form Validation page uses React Hook Form and Zod. If you remove that page and do not plan to validate forms this way:

npm uninstall react-hook-form @hookform/resolvers zod

Keep them if your own forms will use them. Forms shows the pattern.

Other single-page packages

Package Only used by Remove with
input-otp The Input OTP page and src/components/ui/input-otp.tsx npm uninstall input-otp
cmdk The Combobox page and src/components/ui/command.tsx npm uninstall cmdk
embla-carousel-react The Carousel page, src/components/ui/carousel.tsx and the photo Lightbox npm uninstall embla-carousel-react

Delete the component file in src/components/ui/ along with the package. If you keep the Photos app, keep the carousel: the photo viewer needs it.

The Icons page

The Icons page lists every Lucide icon, so it bundles all of them into one file of about 770 KB. That file only downloads when someone opens the Icons page, so it does not slow down the rest of the app. If your users do not need the page, delete src/pages/content/icons/, its route and its menu link.

The nav bar extras

The language menu and the sample data in the notifications, messages and tasks panels are demo content. Nav Bar shows how to remove a button or point it at your own data.

Checking the result

After removing features, run the full build to make sure everything still fits together:

npm run build

Then click through the menu in npm run dev to make sure no link leads to a missing page. A link to a deleted page shows the “Page not found” page.
