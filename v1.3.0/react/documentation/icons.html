Icons

Materia uses Lucide icons through the lucide-react package. Lucide has more than 1,800 icons, and each one is a React component.

Using an icon

Import the icon by name and render it:

import { Bell } from "lucide-react";

<Bell />

The Icons page at /content/icons lists every icon. Search by name and click an icon to copy its JSX, such as <Bell />. You can also browse the full set with categories on lucide.dev/icons.

Vite includes only the icons you import, so using a few icons keeps the site small.

Size and color

import { Bell, Settings, Trash2 } from "lucide-react";

import { IconButton } from "@/components/common/icon-button";
import { Badge } from "@/components/ui/badge";
import { Button } from "@/components/ui/button";

export default function IconSizes() {
	return (
		<div className="flex flex-wrap items-center gap-6">
			<Bell className="size-3.5" />
			<Bell />
			<Bell className="size-5.5" />
			<Bell className="size-8 text-sky-500" />

			<IconButton>
				<Settings />
				<span className="sr-only">Settings</span>
			</IconButton>

			<Button variant="destructive">
				<Trash2 />
				Delete
			</Button>

			<Badge variant="caution">
				<Bell />
				Reminder
			</Badge>
		</div>
	);
}

Every icon starts at the same size. src/styles/base.css sets it once for all Lucide icons:

svg.lucide {
	@apply size-4.5 shrink-0 stroke-[1.6];
}
  • size-4.5 makes each icon 18 pixels, which sits well next to the 14-pixel body text.
  • shrink-0 keeps an icon at full size inside a flex row that runs short of space.
  • stroke-[1.6] draws the lines a little thinner than Lucide’s default of 2.

You only add a size when an icon should differ from the default:

<Bell />                       {/* 18px, the default */}
<Bell className="size-5.5" />  {/* 22px, as in the sidebar rail */}

Icons draw in currentColor, so they take the text color of their parent. To color one icon on its own, give it a text class:

<Bell className="text-sky-500" />

Icons inside components

Some components size the icons inside them, so leave those icons without a class:

Component Icon size inside it
Badge size-3.5
Buttons in the nav bar size-5
Button, IconButton, menu items The default, size-4.5

A Button lays out an icon and a label with a gap between them. Put the icon before or after the text:

<Button variant="destructive">
	<Trash2 />
	Delete
</Button>

Icon-only buttons

A button that shows only an icon needs a label for screen readers. Add it as hidden text with sr-only:

<IconButton>
	<Settings />
	<span className="sr-only">Settings</span>
</IconButton>

Every icon-only button in the template follows this pattern. Lucide marks its icons as aria-hidden, so a screen reader reads only the label.

Icons in data files

Data files can store an icon as a component. src/data/navigation.ts gives each menu item one:

import { ShoppingBag, type LucideIcon } from "lucide-react";

export type NavLink = {
	label: string;
	to: string;
	icon: LucideIcon;
};

{ label: "E-Commerce", to: "/", icon: ShoppingBag },

The sidebar then renders it with a capital letter, the way React expects a component:

<item.icon className="size-5" />

Using a different icon set

Lucide covers what the template needs. To bring in another set, such as Tabler Icons or Heroicons, install its React package and import from it in the same way. Those icons do not get the svg.lucide default size, so give them a size-* class, or add a matching rule to src/styles/base.css.

The Icons page and bundle size

The Icons page imports the whole Lucide set to list it, which makes it the largest page in the build at around 770 KB. It loads only when someone opens that page, so it does not slow down the rest of the site. Delete the page if you do not need it. Removing Features explains how.
