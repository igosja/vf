Data Display

The components on this page show content inside a card or on a page: tables, tabs, accordions, progress and loading states, and small navigation parts.

Table

Table from src/components/ui/table.tsx renders a plain HTML table with the template’s spacing and line colors. Its parts map to HTML elements: TableHeader to <thead>, TableRow to <tr>, TableHead to <th>, TableCell to <td> and so on. The Tables page at /content/tables shows more examples.

import { Badge } from "@/components/ui/badge";
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";

const INVOICES = [
	{ id: "INV-2026-010", date: "Oct 12, 2026", amount: "$49.00", status: "Pending" },
	{ id: "INV-2026-009", date: "Sep 12, 2026", amount: "$49.00", status: "Paid" },
	{ id: "INV-2026-007", date: "Aug 12, 2026", amount: "$49.00", status: "Failed" },
] as const;

const STATUS_VARIANT = { Paid: "positive", Pending: "caution", Failed: "destructive" } as const;

export default function InvoiceTable() {
	return (
		<div className="rounded-2xl bg-card p-6">
			<Table>
				<TableHeader>
					<TableRow>
						<TableHead>Invoice</TableHead>
						<TableHead>Date</TableHead>
						<TableHead>Status</TableHead>
						<TableHead className="text-right">Amount</TableHead>
					</TableRow>
				</TableHeader>
				<TableBody>
					{INVOICES.map((item) => (
						<TableRow key={item.id}>
							<TableCell className="text-emphasis-foreground">{item.id}</TableCell>
							<TableCell>{item.date}</TableCell>
							<TableCell>
								<Badge variant={STATUS_VARIANT[item.status]}>{item.status}</Badge>
							</TableCell>
							<TableCell className="text-right">{item.amount}</TableCell>
						</TableRow>
					))}
				</TableBody>
			</Table>
		</div>
	);
}

The table scrolls sideways on its own when its columns do not fit, so a wide table works on a phone. To hide less important columns on small screens instead, add hidden md:table-cell to the cells of that column, in both the header and the rows.

For sorting, filtering and paging across many rows, add TanStack Table and render its rows with these components. shadcn/ui’s Data Table guide shows how.

Tabs and accordion

Tabs switch between panels in the same place. Accordion stacks sections that open and close. Both work with the keyboard.

import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/components/ui/accordion";
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";

export default function TabsAndAccordion() {
	return (
		<div className="grid gap-8">
			<Tabs defaultValue="overview">
				<TabsList>
					<TabsTrigger value="overview">Overview</TabsTrigger>
					<TabsTrigger value="analytics">Analytics</TabsTrigger>
					<TabsTrigger value="reports">Reports</TabsTrigger>
				</TabsList>
				<TabsContent value="overview" className="pt-3">
					Your store had 2,340 visitors this week.
				</TabsContent>
				<TabsContent value="analytics" className="pt-3">
					Visitors stayed 3 minutes and 12 seconds on average.
				</TabsContent>
				<TabsContent value="reports" className="pt-3">
					Three reports are ready to download.
				</TabsContent>
			</Tabs>

			<Accordion type="single" collapsible defaultValue="shipping">
				<AccordionItem value="shipping">
					<AccordionTrigger>How long does shipping take?</AccordionTrigger>
					<AccordionContent>Orders ship within two business days and arrive in three to five.</AccordionContent>
				</AccordionItem>
				<AccordionItem value="returns">
					<AccordionTrigger>Can I return an item?</AccordionTrigger>
					<AccordionContent>Return any item within 30 days for a full refund.</AccordionContent>
				</AccordionItem>
			</Accordion>
		</div>
	);
}
  • defaultValue sets which tab or section starts open. Use value and onValueChange to control it from your own state.
  • type="single" lets one accordion section open at a time, and collapsible lets it close again. type="multiple" lets several stay open.
  • Collapsible from src/components/ui/collapsible.tsx is a single open-and-close section without the accordion’s styles. The sidebar groups use the same Radix primitive.

The demo pages are at /components/tabs, /components/accordion and /components/collapsible.

Progress, skeleton and spinner

import { Progress } from "@/components/ui/progress";
import { Skeleton } from "@/components/ui/skeleton";
import { Spinner } from "@/components/ui/spinner";

export default function LoadingStates() {
	return (
		<div className="grid gap-6">
			<Progress value={64} aria-label="Upload progress" />

			<div className="flex items-center gap-4">
				<Skeleton className="size-12 rounded-full" />
				<div className="grid flex-1 gap-2">
					<Skeleton className="h-4 w-3/5" />
					<Skeleton className="h-4 w-2/5" />
				</div>
			</div>

			<div className="flex items-center gap-2 text-muted-foreground">
				<Spinner />
				Loading orders
			</div>
		</div>
	);
}
Component Use it for
Progress Progress you can measure, such as an upload or a goal. Takes value from 0 to 100. A text-* class colors it, as Colors shows
Skeleton Placeholders in the shape of content that is still loading. Size each one with classes
Spinner Work you cannot measure. It also fits inside a button, as Button shows

Breadcrumb, pagination and keyboard keys

import { Breadcrumb, BreadcrumbItem, BreadcrumbLink, BreadcrumbList, BreadcrumbPage, BreadcrumbSeparator } from "@/components/ui/breadcrumb";
import { Kbd, KbdGroup } from "@/components/ui/kbd";
import { Pagination, PaginationContent, PaginationEllipsis, PaginationItem, PaginationLink, PaginationNext, PaginationPrevious } from "@/components/ui/pagination";

export default function NavigationParts() {
	return (
		<div className="grid gap-6">
			<Breadcrumb>
				<BreadcrumbList>
					<BreadcrumbItem>
						<BreadcrumbLink href="#">Home</BreadcrumbLink>
					</BreadcrumbItem>
					<BreadcrumbSeparator />
					<BreadcrumbItem>
						<BreadcrumbLink href="#">Components</BreadcrumbLink>
					</BreadcrumbItem>
					<BreadcrumbSeparator />
					<BreadcrumbItem>
						<BreadcrumbPage>Breadcrumb</BreadcrumbPage>
					</BreadcrumbItem>
				</BreadcrumbList>
			</Breadcrumb>

			<Pagination className="justify-start">
				<PaginationContent>
					<PaginationItem>
						<PaginationPrevious href="#" />
					</PaginationItem>
					<PaginationItem>
						<PaginationLink href="#">1</PaginationLink>
					</PaginationItem>
					<PaginationItem>
						<PaginationLink href="#" isActive>
							2
						</PaginationLink>
					</PaginationItem>
					<PaginationItem>
						<PaginationLink href="#">3</PaginationLink>
					</PaginationItem>
					<PaginationItem>
						<PaginationEllipsis />
					</PaginationItem>
					<PaginationItem>
						<PaginationNext href="#" />
					</PaginationItem>
				</PaginationContent>
			</Pagination>

			<KbdGroup>
				<Kbd>⌘</Kbd>
				<Kbd>K</Kbd>
			</KbdGroup>
		</div>
	);
}
  • Breadcrumb shows where a page sits. The content header has its own built-in trail, which Content Header covers. Use this component for a trail inside a page.
  • Pagination renders page links. Mark the current page with isActive, and turn a link off with disabled. The links are plain <a> elements: give each one an href with the page in the address, such as ?page=2, or an onClick that changes the page in your own state.
  • Kbd shows a key, and KbdGroup shows a key combination.

Item

Item from src/components/ui/item.tsx lays out a row with media, a title, a description and actions, the shape of most list rows. It takes variant (default, outline, muted) and size (default, sm, xs):

<Item variant="outline">
	<ItemMedia variant="icon">
		<BadgeCheck />
	</ItemMedia>
	<ItemContent>
		<ItemTitle>Your profile has been verified.</ItemTitle>
		<ItemDescription>Verified profiles show a badge next to the name.</ItemDescription>
	</ItemContent>
	<ItemActions>
		<Button size="sm" variant="outline">
			Review
		</Button>
	</ItemActions>
</Item>

ItemMedia with variant="icon" gives the icon a tile in the avatar shape, and variant="image" frames a picture. Its demo page is at /components/item.

Carousel

Carousel from src/components/ui/carousel.tsx slides through items with arrows, swipe and the arrow keys. It runs on Embla Carousel. The demo page at /components/carousel shows sizes, spacing and a vertical carousel, and the photo viewer in the Photos app builds on it.

Scroll area

ScrollArea from src/components/ui/scroll-area.tsx scrolls its content with a thin custom scrollbar. AppShell uses it for the page itself. Give it a fixed height:

<ScrollArea className="h-72">{/* long content */}</ScrollArea>
