Typography

Materia sets all its text in Figtree and sizes it with Tailwind’s standard type scale.

export default function TypographyScale() {
	return (
		<div className="flex flex-col gap-6">
			<div className="flex flex-col gap-2 font-medium">
				<h1 className="text-3xl">h1. Materia heading</h1>
				<h2 className="text-2xl">h2. Materia heading</h2>
				<h3 className="text-xl">h3. Materia heading</h3>
				<h4 className="text-lg">h4. Materia heading</h4>
				<h5 className="text-base">h5. Materia heading</h5>
				<h6 className="text-sm">h6. Materia heading</h6>
			</div>

			<div className="flex flex-col gap-4">
				<p className="text-lg font-light">This is a lead paragraph. It stands out from regular paragraphs.</p>
				<p>This is body copy. The king, seeing how much happier his subjects were, realized the error of his ways and repealed the joke tax.</p>
				<p className="text-base font-medium text-emphasis-foreground">Are you absolutely sure?</p>
				<p className="text-xs">This line of text is meant to be treated as fine print.</p>
			</div>
		</div>
	);
}

The font

index.html loads Figtree from Google Fonts with every weight from 300 to 900, in regular and italic:

<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=Figtree:ital,wght@0,300..900;1,300..900&display=swap" rel="stylesheet" />

src/styles/index.css makes it Tailwind’s sans-serif font, so font-sans and every element that inherits from <body> use it:

@theme {
	--font-sans: "Figtree", ui-sans-serif, system-ui, sans-serif;
}

Page defaults

src/styles/base.css sets the starting style for text:

body {
	@apply bg-background font-sans text-sm text-foreground antialiased;
}

h1,
h2,
h3,
h4,
h5,
h6 {
	@apply text-emphasis-foreground;
}

Body text is text-sm, 14 pixels, in the foreground color. Headings take the emphasis-foreground color, but no size or weight. You give each heading its size with a class, so a <h5> can look like a card title in one place and a section label in another.

The type scale

Materia uses Tailwind’s default sizes. Each size comes with its own line height.

Class Size Where the template uses it
text-xs 12px Captions, chart labels, badges, helper text under form fields
text-sm 14px Body text, the default for every page
text-base 16px Card titles, page titles in the header, values in lists
text-lg 18px Numbers on the stat cards at the top of each dashboard
text-xl 20px Large numbers, such as the total in the middle of a doughnut chart
text-2xl, text-3xl 24px, 30px The plan price on the Billing page and the greeting on the AI Agent page
text-4xl to text-7xl 36px to 72px Display headings, shown on the Typography page

Weights

Class Weight Where the template uses it
font-light 300 Display headings and lead paragraphs
font-normal 400 Body text
font-medium 500 Card titles, page titles, buttons in menus and important values
font-semibold 600 Prices and totals in the Billing dialogs, and dialog titles

Bold, at 700 and above, appears seldom in the template. Medium carries most of the emphasis.

Text colors

Three theme tokens set the level of a piece of text:

Class Use it for
text-emphasis-foreground Titles, names, important values, the current item
text-foreground Body text, the default
text-muted-foreground Hints, dates, captions, secondary labels

A list row often uses all three: the name in emphasis-foreground, a detail in foreground, and a date in muted-foreground. Theme Tokens lists their values.

Changing the font

  1. Pick a font on Google Fonts and copy its <link> tag.
  2. In index.html, replace the Figtree <link> with the new one.
  3. In src/styles/index.css, put the new family name first in --font-sans:
@theme {
	--font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
}

To host the font files yourself instead, which avoids the request to Google, put the font files in public/fonts/ and declare them in src/styles/index.css:

@font-face {
	font-family: "Figtree";
	font-style: normal;
	font-weight: 300 900;
	font-display: swap;
	src: url("/fonts/figtree.woff2") format("woff2");
}

Then remove the Google Fonts <link> tags from index.html. The rich text editor and the maps inherit the page font, so they change with it. The charts name their font in code, so change it there as well, in src/components/charts/use-chart-theme.ts:

const FONT = { family: "Figtree", size: 10 };
