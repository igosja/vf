Badge and Alert

Badges label a status or a category in a small pill. Alerts show a message in a tinted box. Both take their color from a variant.

Badge

Badge from src/components/ui/badge.tsx. Its demo page is at /components/badge.

import { Badge } from "@/components/ui/badge";

export default function BadgeVariants() {
	return (
		<div className="flex flex-wrap gap-2">
			<Badge>Default</Badge>
			<Badge variant="secondary">Secondary</Badge>
			<Badge variant="destructive">Destructive</Badge>
			<Badge variant="positive">Positive</Badge>
			<Badge variant="caution">Caution</Badge>
			<Badge variant="outline">Outline</Badge>
			<Badge variant="ghost">Ghost</Badge>
		</div>
	);
}
Variant Color Use it for
default Sky Neutral or informational labels: Trial, Planned, Feature
secondary Theme gray Quiet labels: Featured, Blocked, Obsolete
positive Emerald Good states: Paid, Active, Completed, On Track
caution Amber Waiting states: Pending, Past Due, Delayed
destructive Red Bad states: Failed, Canceled, At Risk
outline Border only Labels that should stay quiet on a busy card
ghost None Text that only takes a fill when pointed at, inside a link

positive, caution and destructive are tinted: the color at 10% behind text in the same color. In light mode the text is one shade darker so it reads on the pale tint:

positive: "bg-emerald-500/10 text-emerald-600 dark:text-emerald-500 [a&]:hover:bg-emerald-500/25",

Colors explains which status gets which color.

Icons, links and custom colors

import { ArrowUpRight, BadgeCheck } from "lucide-react";

import { Badge } from "@/components/ui/badge";

export default function BadgeExtras() {
	return (
		<div className="flex flex-wrap items-center gap-2">
			<Badge variant="secondary">
				<BadgeCheck />
				Verified
			</Badge>
			<Badge asChild>
				<a href="#">
					Open Link <ArrowUpRight />
				</a>
			</Badge>
			<Badge className="bg-indigo-500/15 text-indigo-600 dark:text-indigo-400">Indigo</Badge>
			<Badge className="bg-pink-500/15 text-pink-600 dark:text-pink-400">Pink</Badge>
		</div>
	);
}
  • An icon inside a badge shrinks to size-3.5 on its own.
  • With asChild, a link takes the badge’s look and gets a hover color.
  • For a color outside the variants, pass a background and a text class through className. Use the same color for both, the background at /15.

Mapping data to a variant

When a table column holds a status, map each value to a variant once at the top of the file. The Billing History table does this:

const STATUS_VARIANT: Record<InvoiceStatus, ComponentProps<typeof Badge>["variant"]> = {
	Paid: "positive",
	Pending: "caution",
	Failed: "destructive",
};

<Badge variant={STATUS_VARIANT[item.status]}>{item.status}</Badge>;

Record<InvoiceStatus, ...> makes TypeScript check that every status has a variant. Add a new status to the data type and TypeScript points at this map until you give it a color.

Alert

Alert from src/components/ui/alert.tsx, with AlertTitle, AlertDescription and AlertAction. Its demo page is at /components/alert.

import { CircleAlert, CircleCheck } from "lucide-react";

import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

export default function AlertVariants() {
	return (
		<div className="flex flex-col gap-3">
			<Alert>
				<CircleCheck />
				<AlertTitle>Payment successful</AlertTitle>
				<AlertDescription>Your payment of $29.99 has been processed. A receipt has been sent to your email address.</AlertDescription>
			</Alert>
			<Alert variant="destructive">
				<CircleAlert />
				<AlertTitle>Payment failed</AlertTitle>
				<AlertDescription>Your payment could not be processed. Please check your payment method and try again.</AlertDescription>
			</Alert>
		</div>
	);
}
Variant Color Use it for
default Primary Information and success messages
destructive Red Errors and failures

Put a Lucide icon first, and the alert gives it its own column, so the title and the text line up beside it. Without an icon, the text starts at the left edge.

Actions and custom colors

import { TriangleAlert } from "lucide-react";

import { Alert, AlertAction, AlertDescription, AlertTitle } from "@/components/ui/alert";
import { Button } from "@/components/ui/button";

export default function AlertWithAction() {
	return (
		<div className="flex flex-col gap-3">
			<Alert>
				<AlertTitle>Dark mode is now available</AlertTitle>
				<AlertDescription>Enable it under your profile settings to get started.</AlertDescription>
				<AlertAction>
					<Button size="sm">Enable</Button>
				</AlertAction>
			</Alert>
			<Alert className="bg-amber-400/15 text-amber-500">
				<TriangleAlert />
				<AlertTitle>Your subscription will expire in 3 days.</AlertTitle>
				<AlertDescription>Renew now to avoid service interruption or upgrade to a paid plan to continue using the service.</AlertDescription>
			</Alert>
		</div>
	);
}

AlertAction pins a button to the top right corner of the alert. For a warning, the template passes an amber tint through className, the same way as a badge.

Trend

To show a change such as +24.99% with an arrow, use the Trend component. It turns green or red based on the direction. Template Components describes it, and Colors shows it next to the badges.
