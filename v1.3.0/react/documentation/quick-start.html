Quick Start

Materia is an admin dashboard template built with React 19, TypeScript, Vite and Tailwind CSS 4. The components come from shadcn/ui, restyled to the Materia design. Charts use Chart.js, the maps use jsvectormap, the calendar uses FullCalendar and the text editor uses Quill.

This page gets the template running on your computer. The pages after it explain how each part works and how to change it.

What you get

  • Six dashboards: E-Commerce, Analytics, Project Management, CRM, Email Marketing and SaaS
  • Nine apps: User (Profile, Timeline, Photos, Connections, Preferences), File Manager, Contacts, Mail, Messages, AI Agent, Photos, Todo Lists and Calendar
  • Eleven pages: Invoice, Pricing Tables, Billing, Search Results, FAQ, Teams, Login, Register, Forgot Password, Coming Soon and Error
  • Content pages: Typography, Figures, Images, Tables and a searchable list of every icon
  • 25 UI element pages, five form pages, a Charts page and a Maps page
  • Light and dark mode, with a third option that follows the operating system
  • A responsive layout from phones to wide screens, and print styles for pages such as the invoice

Pages and Routes lists every page with its address and its source file.

What you need

Tool Version Notes
Node.js 22.22 or newer React Router 8 needs at least 22.22. Node 24 LTS is a good choice.
npm 10 or newer npm comes with Node.js.
A code editor Any Visual Studio Code works well with the Tailwind CSS IntelliSense extension.

Check your Node.js version in a terminal:

node -v

If the number is lower than 22.22, install a newer version from nodejs.org. A version manager such as nvm or fnm lets you keep several versions side by side.

You do not need to install anything else on your computer. TypeScript, Vite, Tailwind CSS and Prettier come with the template and run through npm run.

Install and run

Your download holds two folders. app is the template’s source code. documentation is this site.

Open a terminal in the app folder and install the packages:

cd app
npm install

Then start the development server:

npm run dev

Vite prints a local address, http://localhost:5173 unless that port is busy. Open it in your browser and you will see the E-Commerce dashboard. Leave the server running while you work: every file you save shows up in the browser right away, and the page keeps its state where it can.

The template ships with a package-lock.json, so npm install gets the exact package versions the template runs on. pnpm, Yarn and Bun also work, but they ignore that lock file and may pick newer versions.

Scripts

Command What it does
npm run dev Starts the Vite development server with live reload
npm run build Checks the TypeScript types, then builds the production site into dist/
npm run preview Serves the production build from dist/ so you can test it before you deploy
npm run typecheck Checks the TypeScript types without building
npm run format Formats every .ts, .tsx and .css file in src/ with Prettier

npm run build stops if TypeScript finds an error. Run npm run typecheck on its own to see every error at once.
