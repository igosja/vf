Charts

Every chart in Materia uses Chart.js 4 through react-chartjs-2, which turns each chart type into a React component: <Line>, <Bar>, <Doughnut>, <Pie>, <Scatter> and <Chart> for mixed charts. The Charts page at /charts shows every type the template uses.

The previews below are the template’s own dashboard cards, running with their real data. Point at a chart to see its tooltip, and switch the preview to Dark to see the chart follow.

A chart card, step by step

This is the Sales History card from src/pages/dashboards/e-commerce/sales-history.tsx, shortened to its chart:

import { addDays } from "date-fns";
import { Line } from "react-chartjs-2";

import { alpha, areaGradient, CHART_COLORS, useChartTheme } from "@/components/charts/use-chart-theme";
import { SALES_HISTORY, type DailySeries } from "@/data/e-commerce";

const points = (series: DailySeries, values: number[]) => values.map((y, i) => ({ x: addDays(series.start, i).getTime(), y }));

export function SalesHistory() {
	const theme = useChartTheme();

	const options = {
		maintainAspectRatio: false,
		interaction: { mode: "index" as const, intersect: false },
		layout: { padding: { left: -5 } },
		scales: {
			x: { type: "time" as const, border: { display: false }, grid: theme.grid, ticks: { ...theme.ticks(), maxTicksLimit: 8 } },
			y: {
				min: 100,
				max: 120,
				border: { display: false },
				grid: theme.grid,
				ticks: { ...theme.ticks(), maxTicksLimit: 7, callback: (label: string | number) => `${label}K` },
			},
		},
		plugins: { legend: { display: false }, tooltip: theme.tooltip },
	};

	return (
		<div className="h-66">
			<Line
				options={options}
				data={{
					datasets: [
						{
							label: "Current Month",
							data: points(SALES_HISTORY, SALES_HISTORY.current),
							fill: true,
							backgroundColor: (context) => areaGradient(context, 0.9, alpha(CHART_COLORS.cyan, 0.2), alpha(CHART_COLORS.cyan, 0)),
							borderColor: CHART_COLORS.cyan,
							borderWidth: 1.25,
							tension: 0.4,
							pointRadius: 0,
							pointHoverBackgroundColor: CHART_COLORS.cyan,
						},
					],
				}}
			/>
		</div>
	);
}

The pieces, in order:

  1. useChartTheme() returns the colors and fonts for the axes, the grid lines and the tooltip in the current color mode. Spread them into the options: grid: theme.grid, ticks: theme.ticks(), tooltip: theme.tooltip. Chart Colors explains each one.
  2. maintainAspectRatio: false lets the chart fill its container. The container sets the height with a class, here h-66. A chart without a height on its container collapses.
  3. interaction: { mode: "index", intersect: false } shows one tooltip with every series at the point under the pointer, anywhere above it, not only on the line itself.
  4. legend: { display: false } hides Chart.js’s own legend. The cards draw a ChartLegend under the chart instead, which matches the rest of the design.
  5. CHART_COLORS holds the palette colors for series, and alpha() fades one for fills.
  6. The data comes from a file in src/data/. Each dashboard card file keeps its options and its helper functions, such as points here, next to the chart.

Bars, lines and mixed charts

Use <Chart type="bar"> to combine bars and a line in one chart. Each dataset then sets its own type. The MRR Movement card stacks three bar series and draws the net total as a line over them:

Here is its chart, shortened to the settings that matter:

<Chart
	type="bar"
	options={{
		maintainAspectRatio: false,
		interaction: { mode: "index", intersect: false },
		scales: {
			x: { stacked: true, border: { display: false }, grid: theme.grid, ticks: theme.ticks() },
			y: { stacked: true, border: { display: false }, grid: theme.grid, ticks: theme.ticks() },
		},
		plugins: { legend: { display: false }, tooltip: theme.tooltip },
	}}
	data={{
		labels: MRR_MOVEMENT.labels,
		datasets: [
			{ type: "line", label: "Net new MRR", data: NET, borderColor: CHART_COLORS.amber, order: 1 },
			{ type: "bar", label: "New", data: MRR_MOVEMENT.new, backgroundColor: CHART_COLORS.emerald, stack: "mrr", order: 2 },
			{ type: "bar", label: "Expansion", data: MRR_MOVEMENT.expansion, backgroundColor: CHART_COLORS.sky, stack: "mrr", order: 2 },
			{ type: "bar", label: "Churned", data: MRR_MOVEMENT.churned, backgroundColor: CHART_COLORS.red, stack: "mrr", order: 2 },
		],
	}}
/>

stacked: true on both axes piles the bars with the same stack name on top of each other. A lower order draws on top, so the line sits over the bars.

Doughnuts and pies

A doughnut takes one dataset with one color per slice:

<Doughnut
	options={{
		maintainAspectRatio: false,
		animation: false,
		cutout: "68%",
		plugins: { legend: { display: false }, tooltip: theme.tooltip },
	}}
	data={{
		labels: PLAN_MIX.map((item) => item.plan),
		datasets: [
			{
				data: MRR,
				backgroundColor: [CHART_COLORS.cyan, CHART_COLORS.sky, CHART_COLORS.purple, CHART_COLORS.amber],
				borderWidth: 2,
				borderColor: theme.pieBorder,
				borderRadius: 5,
			},
		],
	}}
/>

borderColor: theme.pieBorder draws the gaps between slices in the card color, so they look like empty space in both color modes. The number in the middle is a normal element laid over the chart with absolute inset-0.

The legend

ChartLegend from src/components/charts/chart-legend.tsx draws the key under a chart. Each item takes a label and a background class that matches the series color:

<ChartLegend
	items={[
		{ label: "New", color: "bg-emerald-500" },
		{ label: "Expansion", color: "bg-sky-500" },
		{ label: "Churned", color: "bg-red-400" },
		{ label: "Net new MRR", color: "bg-amber-400" },
	]}
/>

Use the class that matches the CHART_COLORS key of the series: CHART_COLORS.emerald goes with bg-emerald-500. Colors lists the pairs.

Dates on an axis

Charts with dates on the x axis use type: "time". Chart.js needs a date library for time axes, and the template connects date-fns through chartjs-adapter-date-fns, imported once in use-chart-theme.ts. Pass each point as { x: timestamp, y: value }, as the points helper above does.

Adding a chart type

Chart.js only includes the parts you register, which keeps the bundle small. src/components/charts/use-chart-theme.ts registers the parts the template uses:

Chart.register(
	ArcElement,
	BarController,
	BarElement,
	CategoryScale,
	DoughnutController,
	Filler,
	LinearScale,
	LineController,
	LineElement,
	PieController,
	PointElement,
	ScatterController,
	TimeScale,
	Tooltip
);

To use a chart type the template does not include, register its parts there. A radar chart needs its controller and its scale:

import { RadarController, RadialLinearScale } from "chart.js";

Chart.register(/* ...the existing parts, */ RadarController, RadialLinearScale);

Then render <Radar> from react-chartjs-2. The Chart.js integration guide lists the parts each chart type needs. If a chart stays blank and the browser console says that something “is not a registered controller”, “element” or “scale”, a part is missing from this list.

Chart sizes on small screens

Each chart fills the width of its card and keeps the height its container sets. Chart.js redraws when the card changes size. For a chart that needs more room on a phone, set a responsive height on the container, such as h-52 md:h-66.
