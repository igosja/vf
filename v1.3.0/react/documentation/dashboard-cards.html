Dashboard Cards

A dashboard is a page of cards in a grid. Each card lives in its own file next to the dashboard’s page.tsx, named after the card: plan-mix.tsx exports PlanMix. This guide builds a new card with a chart and places it on a dashboard.

1. The data

Add the numbers to the dashboard’s data file. For the SaaS dashboard, that is src/data/saas.ts:

export const SIGNUPS = {
	labels: ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"],
	trial: [42, 38, 51, 47, 60, 28, 31],
	paid: [12, 9, 15, 14, 19, 6, 8],
};

2. The card

Create src/pages/dashboards/saas/signups.tsx:

import { Info, UserPlus } from "lucide-react";
import { Bar } from "react-chartjs-2";

import { ChartLegend } from "@/components/charts/chart-legend";
import { CHART_COLORS, useChartTheme } from "@/components/charts/use-chart-theme";
import { IconButton } from "@/components/common/icon-button";
import { Trend } from "@/components/common/trend";
import { Card, CardAction, CardHeader, CardTitle } from "@/components/ui/card";
import { SIGNUPS } from "@/data/saas";

export function Signups() {
	const theme = useChartTheme();

	return (
		<Card>
			<CardHeader className="mb-5">
				<CardTitle className="-mt-0.5 flex items-center gap-3">
					<span className="hidden avatar-mask size-8 place-items-center bg-teal-500/15 text-teal-500 sm:grid">
						<UserPlus />
					</span>
					Signups
				</CardTitle>
				<Trend className="mr-3 hidden sm:flex">12.4%</Trend>
				<CardAction>
					<IconButton>
						<Info />
						<span className="sr-only">Information</span>
					</IconButton>
				</CardAction>
			</CardHeader>

			<div className="mb-5 h-52">
				<Bar
					options={{
						maintainAspectRatio: false,
						interaction: { mode: "index", intersect: false },
						scales: {
							x: { stacked: true, border: { display: false }, grid: { display: false }, ticks: theme.ticks(0, "center") },
							y: { stacked: true, border: { display: false }, grid: theme.grid, ticks: theme.ticks() },
						},
						plugins: { legend: { display: false }, tooltip: theme.tooltip },
					}}
					data={{
						labels: SIGNUPS.labels,
						datasets: [
							{ label: "Paid", data: SIGNUPS.paid, backgroundColor: CHART_COLORS.teal, borderRadius: 4, barThickness: 10 },
							{ label: "Trial", data: SIGNUPS.trial, backgroundColor: CHART_COLORS.cyan, borderRadius: 4, barThickness: 10 },
						],
					}}
				/>
			</div>

			<ChartLegend
				items={[
					{ label: "Paid", color: "bg-teal-500" },
					{ label: "Trial", color: "bg-cyan-500" },
				]}
			/>
		</Card>
	);
}

The parts follow the same order in every dashboard card:

  1. The header. An icon tile and the title on the left, an optional Trend, and small IconButtons on the right in CardAction. The icon tile uses a palette color at /15 with the same color for the icon. Colors lists the classes.
  2. The chart in a container with a fixed height, here h-52. useChartTheme() gives the axes, the grid and the tooltip their colors. Charts explains the options.
  3. The legend, with one background class per series that matches its CHART_COLORS key.

3. Place it on the dashboard

Open the dashboard’s page.tsx and add the card to a column:

import { Signups } from "./signups";

<div className="grid grid-cols-1 gap-4 xl:grid-cols-3">
	<div className="flex min-w-0 flex-col gap-4 xl:col-span-2">
		<MrrMovement />
		<ProductEngagement />
	</div>

	<div className="flex min-w-0 flex-col gap-4">
		<PlanMix />
		<Signups />
	</div>
</div>

Below 1280px, the two columns stack into one.

Cards without a chart

For a list, follow the Plan Mix card: rows with a colored dot, a label and a value. For a table, follow Recent Orders on the E-Commerce dashboard. For the stat cards at the top, open the dashboard’s overview.tsx: each stat card is written out in full, with its icon tile, its number, a badge and a label. Card shows a stat card in a preview.

Making the header buttons work

The IconButtons in the card headers are placeholders. Give each one an onClick, or wrap it in a menu:

<DropdownMenu>
	<DropdownMenuTrigger asChild>
		<IconButton>
			<Download />
			<span className="sr-only">Download</span>
		</IconButton>
	</DropdownMenuTrigger>
	<DropdownMenuContent align="end">
		<DropdownMenuItem>Download as CSV</DropdownMenuItem>
		<DropdownMenuItem>Download as PNG</DropdownMenuItem>
	</DropdownMenuContent>
</DropdownMenu>

Remove the ones you do not need.
