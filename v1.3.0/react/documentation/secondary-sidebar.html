Secondary Sidebar

The app pages have a second sidebar of their own: Mail has folders, Contacts has groups, Todo Lists has filters and lists. SecondarySidebar from src/components/layout/sidebar/secondary-sidebar.tsx builds it.

  • From 1280px, it is a column beside the page content, right next to the main menu rail.
  • Below 1280px, it becomes a drawer. The menu button in the content header opens it, and a back arrow at its top leads to the main menu.

Building one

The Todo Lists sidebar, from src/pages/apps/todo-lists/page.tsx:

function TodoSidebar() {
	return (
		<SecondarySidebar
			title="Todo Lists"
			action={
				<ActionButton>
					<Plus />
					Create New
				</ActionButton>
			}
		>
			<SecondarySidebarLabel>Filters</SecondarySidebarLabel>
			<SecondarySidebarNav>
				<SecondarySidebarLink active>
					<SquareCheckBig />
					Everything
				</SecondarySidebarLink>
				<SecondarySidebarLink>
					<CalendarCheck />
					Today
				</SecondarySidebarLink>
				<SecondarySidebarLink badge={29}>
					<Clock />
					Upcoming
				</SecondarySidebarLink>
			</SecondarySidebarNav>

			<SecondarySidebarLabel>Lists</SecondarySidebarLabel>
			<SecondarySidebarNav>
				{LISTS.map((list) => (
					<SecondarySidebarLink key={list.label} badge={list.count}>
						<FileVideo />
						{list.label}
					</SecondarySidebarLink>
				))}
			</SecondarySidebarNav>
		</SecondarySidebar>
	);
}

Place it first inside a flex row, with the page content beside it:

<div className="flex items-start">
	<TodoSidebar />

	<div className="min-w-0 flex-1 pb-4">
		<ContentHeader>{/* search and actions */}</ContentHeader>
		{/* the page */}
	</div>
</div>

The frame notices the sidebar and narrows its left padding, so the sidebar sits flush against the rail.

The parts

Component What it is
SecondarySidebar The column and the drawer. Props: title, action, drawerAction
SecondarySidebarLabel A small heading above a group of links
SecondarySidebarNav A group of links
SecondarySidebarLink One link: a rounded row with an icon and a label. Props: active, badge

SecondarySidebarLink is a <button>, because the template’s filters change what the page shows without changing the address. Give it an onClick, and set active on the one that is selected:

const [filter, setFilter] = useState("everything");

<SecondarySidebarLink active={filter === "today"} onClick={() => setFilter("today")}>
	<CalendarCheck />
	Today
</SecondarySidebarLink>

badge shows a number at the end of the row, such as unread mail in a folder.

The action button

action puts the page’s main button at the top of the sidebar, such as Compose in Mail or Create New in Todo Lists. Use ActionButton from src/components/common/action-button.tsx for it. It has the light blue action color that the app pages share.

Below 1280px the sidebar is a drawer, and the main button would be hidden inside it. So the app pages show a second copy that floats in the corner of the screen. floating places it there and hides it from 1280px:

<ActionButton floating>
	<Plus />
	<span className="hidden md:inline">Create New</span>
</ActionButton>

The floating button shows only its icon on phones and adds its label from 768px.

The drawer leaves out the action by default, because the floating copy covers it. A page that has no floating button passes drawerAction, and the drawer keeps the button at its top. The AI Agent sidebar does this.
