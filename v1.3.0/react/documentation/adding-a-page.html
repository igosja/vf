Adding a Page

This guide adds an Orders page at /orders, with a table of orders, a link in the sidebar menu and a title in the header. Each step lists the file to change. Keep npm run dev running and you will see each step in the browser as you save.

1. Add the data

Create src/data/orders.ts with a type and some rows. Later you can load the same shape from your server, as Working with Data shows.

export type Order = {
	id: string;
	customer: string;
	date: string;
	total: number;
	status: "Paid" | "Pending" | "Failed";
};

export const ORDERS: Order[] = [
	{ id: "#96474", customer: "Harper Collins", date: "Oct 12, 2026", total: 29.69, status: "Paid" },
	{ id: "#96475", customer: "Liam Turner", date: "Oct 12, 2026", total: 59.38, status: "Failed" },
	{ id: "#96476", customer: "Sofia Martinez", date: "Oct 11, 2026", total: 29.69, status: "Pending" },
];

2. Create the page

Create src/pages/orders/page.tsx. The page exports its component as the default export:

import { Download } from "lucide-react";
import type { ComponentProps } from "react";

import { IconButton } from "@/components/common/icon-button";
import { ContentHeader } from "@/components/layout/content-header";
import { Badge } from "@/components/ui/badge";
import { Card } from "@/components/ui/card";
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";
import { ORDERS, type Order } from "@/data/orders";

const STATUS_VARIANT: Record<Order["status"], ComponentProps<typeof Badge>["variant"]> = {
	Paid: "positive",
	Pending: "caution",
	Failed: "destructive",
};

const usd = (amount: number) => amount.toLocaleString("en-US", { style: "currency", currency: "USD" });

export default function Orders() {
	return (
		<div className="mx-auto w-full max-w-400 pb-4">
			<ContentHeader title="Orders">
				<IconButton className="ml-auto">
					<Download />
					<span className="sr-only">Export</span>
				</IconButton>
			</ContentHeader>

			<Card>
				<Table>
					<TableHeader>
						<TableRow>
							<TableHead>Order</TableHead>
							<TableHead>Customer</TableHead>
							<TableHead className="hidden sm:table-cell">Date</TableHead>
							<TableHead>Status</TableHead>
							<TableHead className="text-right">Total</TableHead>
						</TableRow>
					</TableHeader>
					<TableBody>
						{ORDERS.map((order) => (
							<TableRow key={order.id}>
								<TableCell className="text-emphasis-foreground">{order.id}</TableCell>
								<TableCell>{order.customer}</TableCell>
								<TableCell className="hidden sm:table-cell">{order.date}</TableCell>
								<TableCell>
									<Badge variant={STATUS_VARIANT[order.status]}>{order.status}</Badge>
								</TableCell>
								<TableCell className="text-right">{usd(order.total)}</TableCell>
							</TableRow>
						))}
					</TableBody>
				</Table>
			</Card>
		</div>
	);
}

The wrapper, mx-auto w-full max-w-400 pb-4, is the one the dashboards use. Layout Overview lists the other page widths.

3. Add the route

Open src/routes.tsx and add an entry inside the children of the first route, the one with Component: AppShell. Put it anywhere before the path: "*" entry:

{
	path: "orders",
	lazy: async () => ({ Component: (await import("@/pages/orders/page")).default }),
},

Open http://localhost:5173/orders. The page shows inside the frame, with the sidebar and the nav bar.

For a page without the frame, such as a second sign-in page, add the route to the children of the BlankShell route instead. Its address then starts with /pages/.

4. Add it to the menu

Open src/data/navigation.ts. Import an icon at the top, then add a link to a section:

import { Receipt } from "lucide-react";

{
	label: "Dashboards",
	icon: LayoutGrid,
	items: [
		{ label: "E-Commerce", to: "/", icon: ShoppingBag },
		{ label: "Orders", to: "/orders", icon: Receipt },
		// ...
	],
},

The link appears in the sidebar flyout and in the drawer, and it highlights while the Orders page is open. Sidebar Menu explains groups and new sections.

5. Check the types

npm run typecheck

It should finish with no output. If it reports an error, the message names the file and the line.

Splitting a growing page

When a page passes one screen of code, split it into files in the same folder:

src/pages/orders/
├── page.tsx            the layout: header and grid
├── orders-table.tsx    exports OrdersTable
└── order-dialog.tsx    exports OrderDialog

page.tsx imports the parts with relative paths:

import { OrderDialog } from "./order-dialog";
import { OrdersTable } from "./orders-table";

Keep the default export on page.tsx only. The other files use named exports, which keeps the imports easy to search for.

Starting from an existing page

The fastest way to a new page is often to copy the closest one. To build an app page with a folder sidebar, copy src/pages/apps/todo-lists/. For a dashboard, copy one of the folders in src/pages/dashboards/ and keep the cards you need. Rename the folder, rename the default export, and add the route and the menu link as above.
