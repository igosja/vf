Chart Colors

Chart.js draws on a <canvas>. A canvas cannot read Tailwind classes or follow the .dark class, so charts need their colors handed to them as values. src/components/charts/use-chart-theme.ts does this. It exports five things:

Export What it is
useChartTheme() A hook with the axis, grid and tooltip settings for the current color mode
CHART_COLORS The palette colors for series: sky, emerald, amber and the rest
alpha(color, amount) A palette color at a given opacity, for fills and fades
paletteColor(name) Reads any Tailwind color from the stylesheet as a value Chart.js understands
areaGradient(context, stop, start, end) A vertical fade for the area under a line

useChartTheme

Call it once at the top of a chart card and spread its parts into the options:

const theme = useChartTheme();

options={{
	scales: {
		x: { border: { display: false }, grid: theme.grid, ticks: theme.ticks() },
		y: { border: { display: false }, grid: theme.grid, ticks: theme.ticks() },
	},
	plugins: { legend: { display: false }, tooltip: theme.tooltip },
}}
Part What it holds
theme.grid Grid lines in the muted color, with the small tick marks turned off
theme.ticks(padding, align) Axis labels in Figtree at 10 pixels, in the muted-foreground color. padding defaults to 8 and align to "inner". Bar charts pass theme.ticks(0, "center") to center each label under its bar
theme.tooltip The tooltip box in the tooltip colors, with Figtree text and no color squares
theme.pieBorder The card color, for the gaps between doughnut and pie slices
theme.mode "light" or "dark"

The hook reads these values from the theme tokens in src/styles/themes.css, and reads them again whenever the color mode changes. The charts then redraw in the new colors. Change a token, and the charts follow it.

To change the tooltip’s look for every chart, such as its corner radius or padding, edit the tooltip object inside the hook. For a single chart, spread it and override one setting:

tooltip: { ...theme.tooltip, callbacks: { label: (item) => ` $${item.formattedValue}K` } },

CHART_COLORS

export const CHART_COLORS = {
	sky: paletteColor("--color-sky-500"),
	indigo: paletteColor("--color-indigo-400"),
	purple: paletteColor("--color-purple-400"),
	pink: paletteColor("--color-pink-400"),
	red: paletteColor("--color-red-400"),
	amber: paletteColor("--color-amber-400"),
	lime: paletteColor("--color-lime-500"),
	emerald: paletteColor("--color-emerald-500"),
	teal: paletteColor("--color-teal-500"),
	cyan: paletteColor("--color-cyan-500"),
};

Each key holds the same shade as the palette’s background class, so a chart series and its legend dot match: CHART_COLORS.amber with bg-amber-400. These colors stay the same in light and dark mode. Colors explains which color means what.

The template reads them once, when the page loads, because they never change while the page runs.

alpha

alpha makes a palette color see-through:

alpha(CHART_COLORS.emerald, 0.25); // rgb(0 188 125 / 0.25)

Use it for area fills, faded comparison bars and hover states. Never write a color into a chart as a hex code or RGB numbers. Go through CHART_COLORS and alpha, so changing a color in one place changes it everywhere.

paletteColor

CHART_COLORS covers the colors the template uses. For any other Tailwind color, read it with paletteColor:

const MARKER = paletteColor("--color-amber-600");

The map on the Email Marketing dashboard reads a darker amber for its markers this way. Call paletteColor outside your component, at the top of the file, so it runs once.

Tailwind writes its colors in the oklch() format, and Chart.js cannot read that format when it works out hover colors. paletteColor converts each color to rgb() by drawing it on a one-pixel canvas and reading the pixel back.

Every Tailwind color is available to paletteColor, because src/styles/index.css imports Tailwind with theme(static), which keeps the whole palette in the stylesheet.

areaGradient

The filled line charts fade from the line color at the top to nothing at the bottom:

backgroundColor: (context) => areaGradient(context, 0.75, alpha(CHART_COLORS.emerald, 0.25), alpha(CHART_COLORS.emerald, 0)),
Argument What it is
context The context Chart.js passes to the function. It holds the chart’s size
stop Where the full color ends, from 0 at the bottom to 1 at the top. 0.75 keeps the top quarter at full strength
start The color at the top
end The color at the bottom

backgroundColor takes a function here because the gradient needs the chart’s size, which Chart.js only knows while it draws. Pair it with fill: true on the dataset.

Changing the palette

To change a series color across every chart, point its key at another Tailwind color:

amber: paletteColor("--color-orange-400"),

Then change the matching classes on the page, such as bg-amber-400 on the legend dots, so the legend matches. Colors walks through a full swap.
