Tailwind CSS Setup

Materia uses Tailwind CSS 4. Tailwind 4 keeps its settings in CSS, so the template has no tailwind.config.js. Everything lives in src/styles/index.css, and the @tailwindcss/vite plugin in vite.config.ts builds it.

If you know Tailwind 3, the classes work the same way. The setup moved from a JavaScript file into the stylesheet.

index.css, from top to bottom

Imports. Tailwind comes first, then the animation library and the template’s own files:

@import "tailwindcss" theme(static);
@import "tw-animate-css";
@import "./themes.css";
@import "./base.css";
@import "./utilities.css";
@import "./fullcalendar.css";

theme(static) tells Tailwind to keep every color variable in the stylesheet, including the ones no class uses yet. Charts read colors such as --color-amber-400 from the stylesheet while the page runs, so those variables have to exist even when no class asks for them. Without static, Tailwind drops every variable it thinks is unused.

The dark variant. This line makes dark: classes apply inside <html class="dark">:

@custom-variant dark (&:is(.dark *));

Theme tokens. The @theme inline block turns the variables from themes.css into Tailwind colors, and sets primary, destructive and the two shadows. Theme Tokens covers this block.

Fixed colors. @theme static adds the action colors used by the main button on the app pages.

Font and animations. The last @theme block sets the font, an easing curve and two animations:

Setting Class Used for
--font-sans font-sans Figtree, the font for all text
--ease-spring ease-spring The small overshoot of a switch’s thumb
--animate-typing animate-typing The bouncing dots while the AI Agent writes a reply
--animate-caret-blink animate-caret-blink The blinking cursor in an empty one-time-code box

Breakpoints

Materia uses Tailwind’s default breakpoints:

Prefix Starts at What changes there
sm: 640px The nav bar moves from the bottom of the screen to the right edge
md: 768px Rows of summary boxes inside cards line up four across
lg: 1024px Dashboard cards sit two side by side, and the stat cards four in a row
xl: 1280px The sidebar rail appears on the left, and app sidebars sit beside the content instead of in a drawer
2xl: 1536px Table columns that need the room appear, such as Delivery in Recent Orders

Below xl, the menu opens as a drawer from the button in the content header.

Custom utilities

src/styles/utilities.css adds two classes that Tailwind does not have:

@utility avatar-mask {
	mask-image: url(/img/misc/avatat-mask-image.svg);
	mask-repeat: no-repeat;
	mask-position: center;
	mask-size: 100% 100%;
	aspect-ratio: 1 / 1;
}

@utility no-scrollbar {
	scrollbar-width: none;

	&::-webkit-scrollbar {
		display: none;
	}
}

avatar-mask cuts an element into Materia’s rounded four-lobed shape. Avatars, icon tiles and icon buttons all use it. Because it is a mask, it clips photos and colored fills alike, and it keeps the element square:

import { Bell } from "lucide-react";

export default function AvatarMask() {
	return (
		<div className="flex flex-wrap items-center gap-4">
			<img className="avatar-mask size-12 object-cover" src="/img/contacts/2.jpg" alt="" />
			<span className="grid avatar-mask size-12 place-items-center bg-sky-500 text-lg font-medium text-white dark:text-black">M</span>
			<span className="grid avatar-mask size-12 place-items-center bg-emerald-500/15 text-emerald-500">
				<Bell className="size-5.5" />
			</span>
			<button type="button" className="grid avatar-mask size-12 place-items-center bg-secondary text-emphasis-foreground">
				<Bell />
				<span className="sr-only">Notifications</span>
			</button>
		</div>
	);
}

no-scrollbar hides the scrollbar on an element that still scrolls, such as the sidebar flyout.

Tailwind’s @utility makes these behave like built-in classes, so variants work with them: hover:avatar-mask and md:no-scrollbar are both valid.

Shadows

The template uses two shadows, tinted with the theme’s own color so they look right in both modes:

Class Used for
shadow-md Menus, popovers and other popups
shadow-lg Panels that float over the page, such as the sidebar flyout and the nav bar on phones

Both read --shadow-color from themes.css, so changing that one value changes every shadow.

Animations

tw-animate-css provides the open and close animations that the shadcn components use: animate-in, animate-out, fade-in, zoom-in, slide-in-from-top and the rest. The accordion and collapsible use its animate-accordion-down and animate-collapsible-down classes. You can use the same classes on your own elements. The tw-animate-css documentation lists them all.

Adding your own values

Add a value to the last @theme block in src/styles/index.css, and Tailwind creates the classes for it. A new color:

@theme {
	--color-brand: #7c3aed;
}

This gives you bg-brand, text-brand, border-brand and every other color utility. The same works for spacing, sizes, fonts, shadows and animations. The Tailwind theme variables documentation lists each namespace.

For a one-off value, Tailwind also accepts square brackets, such as w-[37rem]. The template keeps these rare and prefers the nearest standard class, so the spacing stays consistent across pages.

Joining classes with cn()

src/lib/utils.ts exports cn(). It joins class names, skips empty ones, and settles conflicts between Tailwind classes so the last one wins:

import { cn } from "@/lib/utils";

cn("px-4 py-2", isActive && "bg-primary/10 text-primary", className);

Every component in src/components passes its className prop through cn(), so a class you pass from the outside overrides the component’s own class:

<Card className="p-4">...</Card>

The card’s own p-6 gives way to your p-4.

Class order

prettier-plugin-tailwindcss sorts the classes in every className, cn() and cva() call when you run npm run format. You do not need to think about the order. Code Style and Tooling shows the setup.
