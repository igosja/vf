Pages and Routes

Materia uses React Router 8 in its data router mode. One file, src/routes.tsx, lists every page and the address it lives at.

How a page gets its address

src/main.tsx builds the router from the route list and hands it to React:

const router = createBrowserRouter(routes);

createRoot(document.getElementById("root")!).render(
	<StrictMode>
		<ThemeProvider>
			<RouterProvider router={router} />
		</ThemeProvider>
	</StrictMode>
);

src/routes.tsx holds the list. Each entry pairs an address with the file that renders it:

{
	path: "dashboards/crm",
	lazy: async () => ({ Component: (await import("@/pages/dashboards/crm/page")).default }),
},

lazy loads the page only when someone opens it. Vite builds each page into its own file, so a visitor downloads only the pages they open. While the next page downloads, the RouteLoader component shows the loading screen. It waits 150 milliseconds before it appears, so a page that is already cached never flashes it.

The two frames

The route list has two parent routes. Each one wraps its pages in a frame and renders the current page where its <Outlet /> sits.

Frame Address What it draws around the page
AppShell / and everything under it The sidebar, the nav bar, the scroll area and the toast area
BlankShell /pages/login, /pages/register, /pages/forgot-password, /pages/coming-soon, /pages/error Nothing. The page fills the window on its own 
export const routes: RouteObject[] = [
	{
		path: "/",
		Component: AppShell,
		HydrateFallback: () => null,
		children: [
			{
				index: true,
				lazy: async () => ({ Component: (await import("@/pages/dashboards/e-commerce/page")).default }),
			},
			// ...the other pages
			{
				path: "*",
				lazy: async () => ({ Component: (await import("@/pages/not-found")).default }),
			},
		],
	},
	{
		path: "/pages",
		Component: BlankShell,
		HydrateFallback: () => null,
		children: [
			{
				path: "login",
				lazy: async () => ({ Component: (await import("@/pages/pages/login/page")).default }),
			},
			// ...register, forgot-password, coming-soon, error
		],
	},
];
  • index: true makes the E-Commerce dashboard the home page at /.
  • path: "*" catches any address that has no page and shows src/pages/not-found.tsx inside the normal frame.
  • HydrateFallback is what React Router shows while the first lazy page loads. The template returns nothing, because index.html already shows its own loading screen until the page is ready.

Linking between pages

Use React Router’s Link for a link to another page. It changes the page without reloading the browser, so the sidebar, the nav bar and everything else stay in place:

import { Link } from "react-router";

<Link to="/apps/mail">Open the inbox</Link>

NavLink works the same way and also knows when its page is open. The sidebar uses it to highlight the current page:

<NavLink to={item.to} className={({ isActive }) => cn("text-emphasis-foreground", isActive && "text-primary")}>
	{item.label}
</NavLink>

To change the page from code, such as after a form saves, use useNavigate. The Login page sends the visitor to the dashboard this way:

const navigate = useNavigate();

navigate("/");

A plain <a href="/apps/mail"> also works, but it reloads the whole app. Keep plain links for addresses outside the template.

Scroll position

The page scrolls inside the frame’s scroll area, not the browser window. AppShell scrolls that area back to the top whenever the address changes, so a new page always starts at the top.

Adding, renaming and removing pages

  • To rename an address, change its path in src/routes.tsx and its to in src/data/navigation.ts.

Showing your own error screen

The template does not set an error boundary, so if a page throws an error while it renders, React Router shows its built-in error screen. To show your own, add an ErrorBoundary component to the parent route in src/routes.tsx:

import { isRouteErrorResponse, useRouteError } from "react-router";

function AppError() {
	const error = useRouteError();
	const message = isRouteErrorResponse(error) ? `${error.status} ${error.statusText}` : error instanceof Error ? error.message : "Something went wrong";

	return (
		<div className="grid min-h-screen place-items-center p-6">
			<div className="rounded-2xl bg-card p-6">{message}</div>
		</div>
	);
}

export const routes: RouteObject[] = [
	{
		path: "/",
		Component: AppShell,
		ErrorBoundary: AppError,
		// ...
	},
];

React Router renders the closest error boundary above the page that failed. See Error Boundaries in the React Router docs for more.
