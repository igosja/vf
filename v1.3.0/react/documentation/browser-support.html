Browser Support

Materia runs in current versions of Chrome, Edge, Safari and Firefox, on desktop and on phones.

Minimum versions

Browser Minimum Released
Chrome and Edge 111 March 2023
Safari, including every browser on iPhone and iPad 16.4 March 2023
Firefox 128 July 2024

Tailwind CSS 4 sets these numbers. Its stylesheet relies on CSS features that older browsers do not have, such as cascade layers, @property and the color-mix() function. In an older browser the layout breaks and some colors go missing. The Tailwind CSS compatibility page explains the details.

Internet Explorer does not work, and no setting can make it work.

Newer features with a fallback

A few parts of the template use CSS that only the newest browsers support. Older browsers within the minimum versions still show a working page:

Feature Where In a browser without it
field-sizing: content Text areas, and the message box on the AI Agent page The text area keeps its starting height and scrolls instead of growing as you type
text-wrap: balance Field descriptions beside a checkbox or switch, and tooltips Lines break in the normal way

The browserslist setting

package.json holds a browserslist entry:

"browserslist": ["last 2 versions", "not dead", "not ie > 0"]

Some tools read it to decide which browsers to support. It does not lower the floor in the table above, because Tailwind CSS 4 needs those versions whatever the setting says.

Testing on a phone

The development server listens only on your own computer by default. To open the template on a phone on the same Wi-Fi network, start it with the --host flag:

npm run dev -- --host

Vite then prints a network address, such as http://192.168.1.20:5173. Open that address on the phone.
