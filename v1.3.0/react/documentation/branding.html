Logo

src/components/common/logo.tsx holds the logo as an inline SVG with two paths. The back shape uses the secondary color and the front shape uses emphasis-foreground, so the logo follows light and dark mode:

export function Logo({ className }: { className?: string }) {
	return (
		<svg width="40" height="40" fill="none" className={className} aria-hidden="true">
			<path className="fill-secondary" d="..." />
			<path className="fill-emphasis-foreground" d="..." />
		</svg>
	);
}

The template shows it at the top of the sidebar rail, in the menu drawer, on the loading screen between pages and on the welcome form of the Form Templates page. Replace the SVG in this one file and every one of them changes.

To use your own SVG logo:

  1. Open your logo file in a text editor and copy the <path> elements.
  2. Paste them into logo.tsx in place of the two existing paths. Keep the className on each path if you want it to follow the color mode, or set a fixed fill color.
  3. Change width, height and viewBox to match your logo. Keep it close to 40 by 40 pixels so it fits the rail.
  4. React writes attributes in camel case, so fill-rule becomes fillRule and clip-path becomes clipPath.

To use an image file instead, put it in public/img/ and return an <img>:

import { cn } from "@/lib/utils";

export function Logo({ className }: { className?: string }) {
	return <img src="/img/logo.svg" alt="" className={cn("size-10", className)} />;
}

The first loading screen

index.html shows a loading screen while the app starts, before React runs. It cannot use the Logo component, so it has its own copy of the logo SVG and its own colors in a <style> block. When you change the logo, change it here too:

  • The <svg> inside <div id="page-loader"> holds the two logo paths.
  • The <style> block colors them: #page-loader path:first-child for the back shape and #page-loader path:last-child for the front, with .dark versions below.

Favicon

index.html loads two favicons, one for a light browser theme and one for a dark one:

<link rel="icon" type="image/svg+xml" href="/img/favicon/favicon.svg" media="(prefers-color-scheme: light)" />
<link rel="icon" type="image/svg+xml" href="/img/favicon/favicon-dark.svg" media="(prefers-color-scheme: dark)" />

Replace public/img/favicon/favicon.svg and favicon-dark.svg with your own, keeping the names. If you only have one icon, keep a single <link> without the media attribute. For a PNG icon, change the type to image/png.

Primary color

Change the primary color in src/styles/index.css:

--color-primary: #118bff;

Colors explains what follows it and how to change the other colors.

The signed-in user

The nav bar shows a sample profile photo, /img/contacts/2.jpg, in src/components/layout/nav-bar/nav-bar.tsx. Replace it with your user’s photo once your app has sign-in, and connect the Profile, Billing, Settings and Logout items in the same menu to your own pages.
