Nav Bar

The nav bar holds the buttons that every page shares. It lives in src/components/layout/nav-bar/nav-bar.tsx.

From 640px wide, it is a column of round buttons down the right edge of the screen, from top to bottom:

Button What it opens
Profile photo A menu with Profile, Billing, Settings and Logout
Flag A language menu with four sample languages
Search A panel with a search field and recent searches
Bell A panel of notifications, with a count of unread ones
Speech bubble A panel of direct messages, with a count
Check circle A panel of ongoing tasks
Sun or moon The Light, Dark and System menu

On phones, the nav bar moves to a bar across the bottom of the screen. It hides the language, messages and tasks buttons to save room, and adds a menu button that opens the sidebar drawer.

The menus and panels show demo data from src/data/: notifications.ts, messages.ts, search.ts and todo-lists.ts. Connect them to your own data the same way as any page. Working with Data explains how.

Panels

The search, notifications, messages and tasks buttons each open a panel that slides in from the right. They all use the NavPanel component from src/components/layout/nav-bar/nav-panel.tsx:

<NavPanel
	title="Notifications"
	trigger={
		<NavButton>
			<Bell />
			<span className="sr-only">Notifications</span>
		</NavButton>
	}
	actions={
		<>
			<IconButton>
				<CheckCheck />
				<span className="sr-only">Mark all as read</span>
			</IconButton>
		</>
	}
>
	{/* the panel's content */}
</NavPanel>
Prop What it does
trigger The button that opens the panel
title The heading at the top of the panel, also read out by screen readers
actions Small buttons on the right of the heading
children The content of the panel

A panel does not block the page. The page behind it stays visible under a dimmed layer and keeps scrolling. Clicking outside the panel or pressing Escape closes it.

Add a button

Each button is an <li> in the nav bar’s list. Copy one and change its content. A button that opens a panel:

<li>
	<NavPanel
		title="Help"
		trigger={
			<NavButton>
				<LifeBuoy />
				<span className="sr-only">Help</span>
			</NavButton>
		}
	>
		<p>Contact support at help@example.com.</p>
	</NavPanel>
</li>

A button that opens a menu uses DropdownMenu, the way the language button does. Add className="hidden sm:block" to the <li> to keep the button off the bottom bar on phones.

NavButton is a small component at the top of nav-bar.tsx. It gives every button the same round shape, size and hover color, and sizes its icon to size-5.

Counts on a button

The red counts on the notifications and messages buttons come from the Count component in the same file. Place it after the panel, inside an <li> with relative:

<li className="relative">
	<NavPanel title="Notifications" trigger={/* ... */}>
		{/* ... */}
	</NavPanel>
	<Count value="99+" />
</li>

The template passes fixed values. Pass a number from your own data instead, and leave the Count out when the number is zero.

Remove a button

Delete its <li>. Then remove any imports the file no longer uses, or npm run typecheck reports them.

The profile menu

The profile button shows a sample photo, /img/contacts/2.jpg, and the menu items do nothing yet. Once your app has sign-in, show the signed-in user’s photo, and turn each item into a link:

<DropdownMenuItem asChild>
	<Link to="/user/profile">
		<CircleUser />
		Profile
	</Link>
</DropdownMenuItem>

asChild makes the menu item render as the link while keeping the menu’s styling and keyboard support.

The language menu

The language menu shows four sample languages and does not translate anything. The template does not include a translation library. To translate your app, add one such as react-i18next, and switch the language from this menu. If your app has one language, delete the flag button’s <li>.
